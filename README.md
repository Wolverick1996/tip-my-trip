# TipMyTrip

Prototipo web che mette in contatto chi organizza un viaggio con chi conosce davvero la destinazione. Nasce da un'esigenza reale incontrata lavorando come Travel Coordinator.

Progetto di apprendimento: l'obiettivo principale è imparare [Effect](https://effect.website), non costruire un prodotto completo.

## Stack

Next.js · React · TypeScript · Effect · Jest · Tailwind CSS
